# Repository rules

- Use English for repository content, including documentation, code comments, user-facing text, and commit messages.
- Keep private discussion notes in the local `.private/` directory, which Git ignores.
- Never stage, commit, or push private discussion notes, or copy them into tracked files. Do not force-add ignored notes.
- Use the installed `typesafe-ai` skill for TypeSafe work on this project. Read its live documentation before changing API integration or judgment design.
